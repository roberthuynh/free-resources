# Contributing

Thanks for helping keep this list current. The easiest way to help is to [open a suggestion](https://github.com/roberthuynh/free-resources/issues/new?template=suggest.yml) with the tool, the offer and a link to its official page.

## What belongs here

- Free tiers, free credits and student plans that one person can claim, for building something with AI.
- Offers you can confirm on the provider's own page.

## What doesn't

- Programs that need a company, an investor or an accelerator.
- Referral or affiliate links.
- Offers you can only find in a blog post, a news story or a forum thread.
- Tools that are shut down, archived or no longer maintained.

## Pull requests

- Edit `README.md` directly. Put the entry in the step or section where a student would need it.
- Link to the provider's own page, and say what's free, who qualifies, and the catch, such as a card, a deadline or a non-commercial term.
- Keep each entry to a few short sentences, in the same format as its neighbors.
- If a number changed, say in the pull request where you checked it and when.

A GitHub Action checks every link in the README and this guide each week and on every change.
